# 🚀 Que he hecho para crear mi agente de Telegram

¡Hola! Soy **Izan** y aquí te cuento cómo creé mi agente de Telegram desde cero. No era experto en nada de esto, pero con ayuda lo conseguí. 😄

---

## 📋 Resumen

Proyecto realizado durante el ciclo formativo para crear un agente conversacional en Telegram usando **OpenCode**, **Linux** y APIs de **OpenRouter**.

---

## 🛠️ Paso a Paso

### 1️⃣ Reparar el PC del centro
- El ordenador pita al encender 🖥️
- Le comenté a OpenCode la secuencia de sonidos
- Abrí el PC,.solté el cableado y limpié las conexiones
- Soplé con aire a presión para quitar el polvo 💨

### 2️⃣ Instalar Linux Mint en USB
- Descargué la **ISO de Linux Mint** 📀
- Usé **RUFUS** para crear el USB booteable
- Seguí las instrucciones de Raul para configurar todo ✅

### 3️⃣ Configurar la BIOS
- Encendí el PC y accedí a la BIOS ⚙️
- Cambié el orden de arranque para que inicie desde USB
- Ahora Linux arranca automáticamente 🎉

### 4️⃣ Instalar OpenCode
- Descargué OpenCode desde su página oficial 💻
- Lo instalé en la terminal del PC del centro
- Activé todos los requisitos necesarios para SSH 🔐

### 5️⃣ Conectar por SSH
- Configuré OpenCode para acceso remoto desde mi portátil
- Me conecté al PC del centro usando IP, usuario y contraseña
- ¡Listo! Ya podía controlar el PC a distancia 🌐

### 6️⃣ Obtener las API Keys
- **OpenRouter**: Generé mi API Key desde su web 🔑
- **Telegram**: Creé *BotniciusJR_bot* con BotFather 🤖
- Necesitaba ambas para crear el agente

### 7️⃣ Crear el bot con OpenClaw
- Conectado por SSH al PC del centro
- Instalé **OpenClaw** y configuré el bot de Telegram
- Usé un modelo gratuito como pidió Raul
- Configuré que se refresque cada pocas horas ⏰

### 8️⃣ Probar el agente
- Abrí Telegram y hablé con mi bot
- Pedí la previsión del tiempo ☁️
- Saludé al profesor 👋
- ¡Funcionando perfectamente! ✅
